# AI Cẩm Trung V1.0

Website Chatbot thử nghiệm chạy hoàn toàn ở phía trình duyệt.

## Cấu trúc

- index.html: giao diện
- style.css: giao diện/kiểu dáng
- app.js: logic chat và tìm FAQ
- data/faq.json: kho câu hỏi – trả lời mẫu

## Chạy thử

Cách đơn giản nhất:
1. Mở thư mục bằng VS Code.
2. Cài extension Live Server (nếu muốn).
3. Nhấp chuột phải vào index.html -> Open with Live Server.

Hoặc tải toàn bộ thư mục lên GitHub và bật GitHub Pages.

## Lưu ý

Bản này CHƯA gọi API AI và chưa xử lý dữ liệu cá nhân. Nó dùng tìm kiếm từ khóa trong FAQ.
Đây là nền móng an toàn để kiểm thử giao diện trước khi kết nối mô hình AI.
